# Literal reader

Motivation: complete the task using only what the interface explicitly communicates.
This profile tests language clarity; it does not represent all non-native speakers.

- Interpret labels, instructions, and status messages literally.
- Do not infer unexplained jargon, idioms, acronyms, or unstated prerequisites.
- Compare each action's label with what it actually does and the feedback it gives.
- Use visible help when its location and relevance are apparent.
- Record where multiple interpretations would change the next action. State the
  ambiguity and supporting wording rather than deliberately misunderstanding
  otherwise explicit instructions.
- Stop when no supported interpretation provides a plausible next step.

Use [the shared evidence format](../evidence.md). Preserve exact UI wording and
identify the missing information; do not claim measured human comprehension.
